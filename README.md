# assets-publicos

Imagens públicas do Grupo Setta (logos, ícones) usadas em e-mails, fluxos e outros projetos.
Cada arquivo abre direto em:
`https://raw.githubusercontent.com/gruposetta/assets-publicos/main/<pasta>/<arquivo>`

**O repositório é público.** Só material de marca e ícones, nunca nada sigiloso.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `marca/` | Logo oficial da Setta (versão amarela). Use daqui em projetos novos. |
| `sgv/` | Ícones dos e-mails do fluxo de Gestão de Viagens (SGV). Tem uma cópia da logo porque o fluxo monta todos os endereços a partir desta pasta. |

Para um projeto novo, crie uma pasta com o nome dele (por exemplo `rh/`) e coloque lá os ícones dele.
